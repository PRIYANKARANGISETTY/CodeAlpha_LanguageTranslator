# 🌍 AI Language Translator

A simple AI-powered language translation tool built using Python and Streamlit.

## Features
- Translate text between multiple languages
- Easy-to-use UI
- Fast translation
- Copy-friendly output

## Technologies Used
- Python
- Streamlit
- deep-translator

## Installation

```bash
pip install -r requirements.txt
```

## Run Project

```bash
streamlit run app.py
```
